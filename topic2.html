CSS & JavaScript

Style your pages with CSS and add interactivity with JavaScript.

What is CSS?

CSS (Cascading Style Sheets) controls how HTML elements look on screen. CSS rules follow a selector { property: value; } pattern. The word "cascading" means styles are applied in priority order: browser defaults → external stylesheet → internal style → inline style.

/* Select all paragraphs and style them */
p {
  color: #333;
  font-size: 1rem;
  line-height: 1.7;
  margin-bottom: 1rem;
}

/* Class selector */
.card {
  background: white;
  border-radius: 12px;
  padding: 1.5rem;
  box-shadow: 0 4px 16px rgba(0,0,0,0.1);
}

/* ID selector */
#hero {
  background: navy;
  color: white;
  padding: 4rem 1rem;
}

The CSS Box Model

Every HTML element is a rectangular box. The box model describes how space is calculated around an element:

  • Content — the actual text or image
  • Padding — transparent space inside the border
  • Border — a line around the padding
  • Margin — transparent space outside the border
/* box-sizing: border-box makes width include padding + border */
* {
  box-sizing: border-box;
}

.element {
  width: 300px;
  padding: 20px;
  border: 2px solid #ccc;
  margin: 16px auto;
}

CSS Flexbox

Flexbox is a one-dimensional layout system for arranging items in a row or column. It makes aligning and distributing space between items much easier than older CSS techniques.

/* Flex container */
.nav-inner {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}

/* Flex item — take up remaining space */
.flex-grow {
  flex: 1;
}

/* Column direction on mobile */
.card-group {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}

CSS Grid

Grid is a two-dimensional layout system that allows precise control over rows and columns simultaneously. It's ideal for page layouts and card grids.

/* 3-column card grid */
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1.5rem;
}

/* Responsive: auto-fit adjusts column count automatically */
.auto-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 1.5rem;
}

/* Item spanning multiple columns */
.featured {
  grid-column: span 2;
}

Responsive Design with Media Queries

Media queries apply CSS rules only when certain conditions are met — most commonly, minimum or maximum screen widths. This is the foundation of responsive web design and mobile-first development.

/* Mobile first: default styles apply to all screens */
.card-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

/* Tablet: 2 columns at 600px and wider */
@media (min-width: 600px) {
  .card-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop: 3 columns at 900px and wider */
@media (min-width: 900px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr);
    gap: 1.5rem;
  }
}

/* Hide element on mobile, show on desktop */
.desktop-only {
  display: none;
}
@media (min-width: 768px) {
  .desktop-only {
    display: block;
  }
}

JavaScript Fundamentals

JavaScript is the programming language of the web. It runs in the browser and allows you to respond to user actions, modify the DOM, validate forms, and much more.

// Variables
const name = "Rewired";
let score  = 0;

// Functions
function greet(person) {
  return `Hello, ${person}!`;
}
console.log(greet("World"));

// Arrow function
const double = (n) => n * 2;

// Conditional
if (score >= 80) {
  console.log("Great job!");
} else {
  console.log("Keep practicing.");
}

// Loop
const items = ["HTML", "CSS", "JavaScript"];
items.forEach(item => {
  console.log(item);
});

DOM Manipulation

The Document Object Model (DOM) is a tree representation of the HTML page. JavaScript can read and modify any element, attribute, or content in the DOM.

// Select elements
const btn     = document.getElementById('myBtn');
const heading = document.querySelector('h1');
const cards   = document.querySelectorAll('.card');

// Change content and style
heading.textContent = "Updated Heading";
heading.style.color = "#00c2a8";

// Add / remove CSS classes
btn.classList.add('active');
btn.classList.remove('hidden');
btn.classList.toggle('open');

// Listen for events
btn.addEventListener('click', () => {
  alert('Button clicked!');
});

// Create and insert new elements
const newP = document.createElement('p');
newP.textContent = "Dynamically added paragraph.";
document.body.appendChild(newP);
