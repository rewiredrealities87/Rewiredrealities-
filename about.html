About This Site

Rewired Realities was created as a capstone project for IT 3203 — Web Development. The goal was to build a fully functional, responsive, multi-page website demonstrating proficiency in:

  • Semantic HTML5 document structure
  • CSS styling — layout, typography, color, and selectors
  • Responsive design with media queries (mobile-first)
  • JavaScript interactivity (quiz application)
  • Clean, organized, commented code
  • Deployment via GitHub Pages

What I Learned

Building this project taught me how much goes into creating even a simple website. Some key takeaways:

  • Mobile-first CSS is much cleaner than trying to override desktop styles for smaller screens.
  • CSS Grid and Flexbox together handle virtually any layout challenge.
  • Semantic HTML matters — it makes code readable and improves accessibility.
  • JavaScript DOM manipulation is powerful but requires understanding how the browser parses and renders HTML first.
  • Good code organization and comments pay off when you return to a project after a break.
