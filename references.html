References & Resources

The following sources were used to research and support the content throughout this site. Each reference includes a brief explanation of how it was used.

  1. Reference 01
    MDN Web Docs — HTML Reference

    The MDN HTML reference was the primary resource for understanding semantic elements, form controls, and HTML5 attributes. It was consulted extensively for the HTML topic page and the concepts glossary.

  2. Reference 02
    MDN Web Docs — CSS Reference

    Used to research CSS properties including Flexbox, Grid, custom properties (CSS variables), and media query syntax. MDN's interactive examples were especially useful for understanding layout behavior.

  3. Reference 03
    MDN Web Docs — JavaScript Reference

    The authoritative reference for JavaScript language features, DOM API methods such as querySelector, addEventListener, and classList. Referenced throughout the quiz.js development.

  4. Reference 04
    W3Schools — HTML Tutorial

    W3Schools provided beginner-friendly examples and Try It Yourself editors that helped test HTML concepts quickly. Used as a supplemental reference alongside MDN for the HTML topic page.

  5. Reference 05
    W3Schools — CSS Tutorial

    Used to understand the CSS Box Model, CSS selectors, and CSS transitions. The visual diagrams on W3Schools were helpful for conceptualizing how padding, margin, and border interact.

  6. Reference 06
    CSS-Tricks — A Complete Guide to Flexbox

    This guide is considered the definitive visual reference for CSS Flexbox. It was used to correctly implement the responsive navigation bar and the two-column layout on the homepage, particularly for align-items and justify-content properties.

  7. Reference 07
    CSS-Tricks — A Complete Guide to Grid

    Referenced when building the responsive card grid layout. The guide clearly explains grid-template-columns, repeat(), fr units, and the auto-fit keyword used throughout this project.

  8. Reference 08
    web.dev — Responsive Web Design Basics

    Google's web.dev platform provided the foundational reading on responsive design principles, including the viewport meta tag, mobile-first strategy, and fluid layouts. Directly influenced the CSS media query structure used in this project.

  9. Reference 09
    W3C WAI — Introduction to Web Accessibility

    The W3C Web Accessibility Initiative guidelines informed decisions such as adding lang attributes, alt text on images, ARIA labels on interactive elements, and ensuring sufficient color contrast throughout the site.

  10. Reference 10
    GitHub Docs — GitHub Pages

    Used to understand how to enable and configure GitHub Pages for static site hosting. Referenced for setting up the deployment branch and understanding how the live URL is generated from the repository.

  11. Reference 11
    MDN — Using Media Queries

    This specific MDN guide covers media query syntax in depth, including min-width, max-width, and the mobile-first approach. Directly applied to the CSS breakpoints implemented in style.css.

  12. Reference 12
    The Modern JavaScript Tutorial — javascript.info

    An in-depth open-source JavaScript course covering language fundamentals and DOM interaction. Used as a reference when writing the quiz grading logic, event listeners, and dynamic DOM updates in quiz.js.
