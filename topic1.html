HTML Fundamentals

HyperText Markup Language — the structural backbone of every webpage.

What is HTML?

HTML (HyperText Markup Language) is the standard language used to create and structure content on the web. A web browser reads HTML and renders it as a visual webpage. HTML uses elements represented by tags to describe different types of content.

Every HTML document follows this basic skeleton:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <!-- Visible content goes here -->
  </body>
</html>

The <head> contains metadata (not visible to users), while the <body> contains everything shown on screen.

Semantic HTML5 Elements

Semantic elements clearly describe their purpose to both the browser and developers. They improve accessibility, SEO, and code readability compared to using generic <div> tags everywhere.

ElementPurposeExample Use
<header>Introductory content or navigationSite logo and nav
<nav>Navigation linksMenu bar
<main>Primary page contentArticle body
<section>Thematic grouping of contentFeature section
<article>Self-contained contentBlog post
<aside>Tangential contentSidebar
<footer>Footer informationCopyright, links
<figure>Illustration or diagramImage with caption

HTML Forms

Forms collect user input. The action attribute specifies where form data is sent; method specifies GET or POST. Each input should have a label for accessibility.

<form action="/submit" method="post">

  <label for="name">Name:</label>
  <input type="text" id="name" name="name" required>

  <label for="email">Email:</label>
  <input type="email" id="email" name="email">

  <label for="level">Experience:</label>
  <select id="level" name="level">
    <option value="beginner">Beginner</option>
    <option value="intermediate">Intermediate</option>
  </select>

  <button type="submit">Submit</button>

</form>

Key HTML Attributes

Attributes provide additional information about elements. They appear inside the opening tag as name="value" pairs.

  • id — unique identifier for an element (used by CSS and JS)
  • class — assigns CSS classes (multiple elements can share a class)
  • href — URL for anchor links
  • src — source file for images and scripts
  • alt — alternative text for images (accessibility requirement)
  • lang — declares the language of the document (<html lang="en">)
  • data-* — custom data attributes for JavaScript use
